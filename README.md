C Typing Speed Test

A terminal-based typing speed test developed in C that measures typing speed, accuracy, and completion time. The application includes multiple difficulty levels and a persistent leaderboard using file handling.

For example:

The program starts the timer when the user begins typing and stops it when they press Enter.

WPM Calculation

The program uses the standard typing-test convention of considering 5 characters as one word.

The formula used is:

WPM = (Characters Typed / 5) / Time in Minutes

For example, if the user types 300 characters in 1 minute:

WPM = (300 / 5) / 1
    = 60 WPM

The program calculates the time using the clock() function from time.h.

clock_t start = clock();

fgets(typed, MAX_TEXT, stdin);

clock_t end = clock();

The difference between end and start gives the time taken.

Accuracy Calculation

Accuracy is calculated by comparing the characters typed by the user with the original sentence.

For every character that matches, the program increases the correct counter.

for (i = 0; i < maxLength; i++) {
    if (original[i] == typed[i])
        correct++;
}

The accuracy formula is:

Accuracy = Correct Characters / Typed Characters × 100

The result is displayed as a percentage.

Example:

Accuracy : 96.50%

index = rand() % EASY_COUNT;

srand(time(NULL));

File Handling

The leaderboard is stored in a file called:

leaderboard.txt

The program uses C file handling functions to store and retrieve scores.

Saving a score

The file is opened in append mode:

file = fopen("leaderboard.txt", "a");

The score is then written using:

fprintf(file, "%s %.2f %.2f\n",
        score.name,
        score.wpm,
        score.accuracy);

Finally, the file is closed:

fclose(file);

Using append mode means that previous scores are not deleted when a new score is added.

Loading scores

The program opens the file in read mode:

file = fopen("leaderboard.txt", "r");

Scores are read using:

fscanf(file, "%49s %f %f",
       scores[count].name,
       &scores[count].wpm,
       &scores[count].accuracy);
Leaderboard

The leaderboard displays the top scores based on WPM.

Example:

============================================
              LEADERBOARD
============================================

Rank   Name                 WPM        Accuracy
------------------------------------------------
1      Lenny                72.41      98.32%
2      Alex                 65.73      96.21%
3      Chris                58.42      94.50%
============================================

The program uses Bubble Sort to arrange the scores from highest to lowest WPM.

if (scores[j].wpm < scores[j + 1].wpm) {
    temp = scores[j];
    scores[j] = scores[j + 1];
    scores[j + 1] = temp;
}
